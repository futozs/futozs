Full-stack fejlesztő, Miskolc.

Weboldalakat és webes rendszereket építek az adatbázistól a felületig, és a szervert is én üzemeltetem alattuk. Leginkább Next.js-ben és TypeScriptben dolgozom.

A munkáim nagy része privát repóban van, ezért itt kevés látszik belőlük. A teljes lista a [futozs.hu/munkak](https://futozs.hu/munkak) oldalon van, élő linkekkel.

#### Nyílt forrás

[**kassza**](https://github.com/futozs/kassza)\
Hivatalos Számlázz.hu plugin: nulla függőségű TypeScript kliens a Számla Agent API-hoz. Dokumentáció: [kasszajs.hu](https://kasszajs.hu)

[**kreta-ora**](https://github.com/futozs/kreta-ora)\
KRÉTA órarend iOS-re, Apple Watchra és Androidra. Widgetek, számlapkomplikációk, és értesítés, ha változik az órarend. Nem hivatalos.

[**moat**](https://github.com/futozs/moat)\
Egy éles Ubuntu szerver felépítése rétegenként: SSH, WireGuard, tűzfal, DDoS-védelem, mentés. Minden beállítás mellett ott az oka.
